A repository-level license badge does not establish the license for every asset; retain per-file notices and verify the exact origin of adapted files.

## Owner asset decisions

- **Typewriter Variable font:** `CMU Typewriter Text Variable Width` is selected in both tracked Kitty Everforest theme files and `CMU Typewriter Text` is requested in three Cassini QuickShell elements. The font's source files also include CSS and alternate webfont formats. If the font is absent, Kitty/Qt will use their configured fallback fonts, changing terminal and Cassini typography but not preventing the configs from loading. Recommendation: keep the existing OFL files and installation step unless the owner prefers a separately verified system package; do not relicense font data. The bundled OFL reserves the “Computer Modern Unicode fonts” family name and requires accompanying license/copyright information.
- **Task-bar profile photo:** task-bar config points to `~/.config/quickshell/task-bar/profile.jpg`; `Header.qml` uses a name initial when the image is unavailable, and the hub settings expose a user-settable path. `WideDrawer.qml` also refers to a relative profile image. Absence therefore removes only the photo/avatar treatment. Recommendation: leave it optional and use an owner-supplied untracked image; do not fetch or commit a personal image without approval.
- **Top-bar profile photo:** retained manual-use top-bar points to `~/.config/quickshell/snes-hub/profile.jpg`; its header uses the profile name fallback. Same recommendation: optional, owner-supplied, untracked.
- **Startup sound:** `hyprland.lua` starts `mpv` only when `~/.config/hypr/sounds/startup.wav` exists. Missing audio is silent and does not stop startup. Recommendation: keep optional and do not add a sound asset without owner approval.

## Proposed scope

`docs/LICENSE-PROPOSAL.md` drafts an owner-only license scope. No top-level `LICENSE` is added by this workstream. The owner should resolve the unlicensed `snes19xx`-attributed and mixed QuickShell/assets groups before treating a repository-wide license as complete.
